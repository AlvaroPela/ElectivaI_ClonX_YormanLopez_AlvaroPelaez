# ElectivaI_ClonX_YormanLopez_AlvaroPelaez

**Nombre de la Materia:** Electiva I

**Nombre del Proyecto:** Clon de X (Nexo)

**Equipo:** YormanLopez_AlvaroPelaez

**Integrantes:**
* Yorman Lopez
* Alvaro Pelaez

**Descripción:**
Clon de la red social X hecho como SPA con React y Firebase. Permite registrarse con un nombre de
usuario único, iniciar sesión con usuario o con Google, publicar tweets con imagen, comentar,
seguir usuarios y ver el feed, los perfiles y las listas de seguidores y seguidos paginados de 10 en 10.

Versión en línea: https://facturasweb.homemediaruffo.uk

**Requerimientos:**
* Node.js 24 y Yarn
* React 19, TypeScript, Vite y React Router
* Bootstrap y lucide-react
* Firebase Authentication y Cloud Firestore

**Instrucciones de compilación y ejecución:**
1. Clonar el repositorio y entrar a la carpeta `clon_x`.
2. Ejecutar `yarn install`.
3. Ejecutar `yarn dev` y abrir http://localhost:5173.
4. Para producción, ejecutar `yarn build` (los archivos quedan en `clon_x/dist`).
